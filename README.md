# CubeCoach

**Train smarter. Solve faster.**

A responsive, local-first speedcubing trainer for 3×3, 2×2, and Skewb.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

The Vite base path is configured for `/cube-coach/`. Build the project and deploy the `dist` directory to the repository's Pages branch or GitHub Actions workflow.
